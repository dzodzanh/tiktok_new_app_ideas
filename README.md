# tiktok_new_app_ideas

Hàng chờ đăng TikTok cho 2 app đang test ý tưởng: Stombers và Crossi.
Trang: https://dzodzanh.github.io/tiktok_new_app_ideas/

Sinh ra bởi `scripts/build_queue.py --site=new_apps_site --apps=stombers,crossi`.

## research/
Báo cáo nghiên cứu đối thủ / format viral (viết tay, không do build_queue sinh ra).
https://dzodzanh.github.io/tiktok_new_app_ideas/research/ — thêm báo cáo mới: tạo `research/<slug>/index.html` và thêm một thẻ vào `research/index.html`.
